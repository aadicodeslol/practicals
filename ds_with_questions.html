Q1. Mean, Median and Mode for Grouped Data

For the given grouped frequency distribution, calculate the arithmetic mean, median and mode.

ANSWER / R CODE
lb = seq(0, 70, 10)
ub = seq(10, 80, 10)
w = 10
f = c(6, 8, 15, 24, 19, 14, 12, 7)
n = sum(f)
cf = cumsum(f)
x = (lb+ub)/2
mean = sum(f*x)/n
mc = min(which(cf >= n/2))
median = lb[mc] + w*(n/2 - cf[mc-1])/f[mc]
moc = which(f == max(f))
d1 = f[moc] - f[moc-1]
d2 = f[moc] + f[moc-1]
mode = lb[moc] + (w+d1)/(d1+d2)
cat(mean,median,mode)

q1c = min(which(cf >= n/4))
q1 = lb[q1c] + w * ((n/4 - f[q1c - 1]) / f1[q1c])
print(q1)

q3c = min(which(cf >= 3 * n/4))
q3 = lb[q3c] + w * ((3 * n/4 - f[q3c - 1]) / f1[q3c])

Q1. Spearman's Rank Correlation

Using the given ranks, calculate Spearman's rank correlation coefficient.

ANSWER / R CODE
rank_x <- c(1, 3, 5, 7, 2, 4, 6)
rank_y <- c(2, 5, 4, 6, 1, 3, 7)
n <- length(rank_x)
d <- rank_x - rank_y
d2 <- sum(d^2)
deno <- n * (n^2 - 1)
rho <- 1 - ((6 * d2) / deno)
cat("Spearman Rank Correlation:", rho)
